# ちず・こっきクイズ（いぶちゃん＆みーちゃん）

4〜5さい むけの、にほんちず・せかいちず・こっきの クイズアプリです。

## あそびかた
- **にほんモード**（パートナー：イーブイ）
  - ちほう／けん／めいさん／めいしょ の 4レベル
- **せかいモード**（パートナー：ひこうタイプの ポケモン）
  - たいりく／くに／こっき／くにの もの・あいさつ の 4レベル
- **たんけん**：ちずを じゆうに タップして、けんや くにの なまえ・めいさん・あいさつを きける
- **ぬりつぶし**：せいかいした けん・くにに いろが ついて、ちずが かんせいしていく
- ホームがめんに ついかすると、アプリとして ぜんがめんで ひらける（PWA）

## しりょう・ライセンス
- にほんちず：地球地図日本（国土地理院）を dataofjapan/land で GeoJSON にしたもの
- せかいちず：Natural Earth（パブリックドメイン）
- こっき：lipis/flag-icons（MIT）
- 3Dの え：Microsoft Fluent Emoji（MIT）
- ポケモンの え・なきごえ：PokeAPI
